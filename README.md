## 🔐 Ética e boas práticas

Todo conteúdo prático será desenvolvido em **laboratórios próprios ou ambientes com autorização expressa**.

Não serão publicados tokens, senhas, chaves, dados pessoais, arquivos de máquinas, respostas prontas (*flags*) ou instruções que violem regras das plataformas. A documentação prioriza **compreensão técnica**, não a reprodução de gabaritos.
